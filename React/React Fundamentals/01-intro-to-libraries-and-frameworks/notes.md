# Introduction to JavaScript Libraries and Frameworks (Theory)

FCC module 1 of React Fundamentals — 6 passages.

Workflow: read a passage in FCC, come back here, answer in your own words.
If you can't answer without re-reading, you didn't learn it yet.

---

## 1. What Is the Role of JS Libraries and Frameworks, and Why Are They Used in the Industry?

**Q1.** What is the difference between a library and a framework?

**Q2.** What specific problem did teams have with vanilla JS that made libraries worth adopting?

**Q3.** Name one real cost or tradeoff of adding a framework to a project.

---

## 2. What Are Single Page Applications, and What Are Some Issues Surrounding Them?

**Q1.** In a traditional multi-page site, what happens when you click a link? In an SPA, what happens instead?

**Q2.** What does the server actually send on the first request to an SPA?

**Q3.** Name two downsides of SPAs.

**Q4.** Your expense tracker was vanilla JS on one HTML page. Was it an SPA? Why or why not?

---

## 3. What Is React, and What Is It Commonly Used For?

**Q1.** Is React a library or a framework? Defend the answer.

**Q2.** What is React's actual job — what does it do that you'd otherwise do by hand?

**Q3.** In your vanilla projects you wrote things like `element.textContent = value` to update the page. What does React have you do instead?

---

## 4. What Are Components in React, and How Do They Work?

**Q1.** What *is* a component, in plain terms?

**Q2.** What are the rules for a valid React component? (naming, return value)

**Q3.** Why break a UI into components instead of writing one big block?

**Q4.** Sketch (in words) how you'd split your expense tracker UI into components.

---

## 5. How Do Default and Named Exports Work in React Components?

**Q1.** Write the syntax for a default export and its matching import.

**Q2.** Write the syntax for a named export and its matching import.

**Q3.** How many default exports can one file have? How many named exports?

**Q4.** With a default export, can the importing file rename it freely? What about a named export?

---

## 6. What Is Vite, and How Can It Be Used to Set Up a New React Project?

**Q1.** What problem does a build tool solve — why can't the browser just run your React files directly?

**Q2.** What command scaffolds a new Vite + React project?

**Q3.** What does the dev server give you that opening an HTML file does not?
